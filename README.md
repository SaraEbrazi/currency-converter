
Currency Converter 💱

A responsive currency converter built with React.

Features

- Currency conversion
- Live exchange rate fetching
- Dynamic currency selection
- Responsive user interface
- Conversion result modal

Technologies

- React
- JavaScript
- Tailwind CSS
- Vite
- Lucide React

API

Exchange rates are fetched from "NerkhAra API" (https://nerkhara.com/en/api/).

Installation

Clone the repository:

git clone https://github.com/SaraEbrazi/currency-converter.git

Navigate to the project directory:

cd currency-converter

Install dependencies:

npm install

Start the development server:

npm run dev
